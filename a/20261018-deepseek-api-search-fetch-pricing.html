DeepSeek 公布 API 網頁搜索與抓取收費　每千次成功請求 5 元

DeepSeek announces pricing for API web search and fetch: 5 yuan per 1,000 successful calls

DeepSeek 公布 API 网页搜索与抓取收费　每千次成功请求 5 元

DeepSeek 發布公告，指其 API 現已支持網頁搜索與抓取，按請求次數收費，單價為每 1000 次成功請求 5 元。目前用戶在 DeepSeek Harness、Claude Code、Codex 透過 Server 端工具調用的 Search／Fetch 接口暫未計費，將於 2026 年 11 月 1 日零時起收費。兩項接口均採用 DeepSeek 自研搜索引擎，為 Agent 與檢索應用提供實時網頁內容。
