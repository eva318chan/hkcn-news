DeepSeek 開源推理引擎 DeepInfer　支援輝達及華為昇騰晶片

DeepSeek open-sources DeepInfer, the inference engine behind V4.1-Flash

DeepSeek 开源推理引擎 DeepInfer　支持辉达及华为升腾芯片

中國 AI 公司 DeepSeek 將自家推理框架 DeepInfer 開源，喺 GitHub 以寬鬆嘅 Apache 2.0 授權發布。據講 DeepInfer 正係支撐 DeepSeek-V4.1-Flash 模型大規模生產服務嘅引擎，支援輝達 SM100 GPU 同華為昇騰 950 NPU 兩種晶片，並喺開源 vLLM 引擎基礎上，加入 DeepSeek 自家系統研究成果，包括 FlashMLA、DeepGEMM、DeepEP 等自研核心、推測解碼同結構化輸出等功能。今次開源等如將 DeepSeek 控制推理成本嘅生產方案交畀社群，正值企業運行 AI agent 面對龐大推理成本之際，亦顯示中國製晶片喺 AI 推理軟件上獲提升至一線地位。
