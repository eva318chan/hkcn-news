Security Bureau launches national security picture books for young children

保安局推出维护国安教育绘本 向幼童传扬守法意识

保安局今日舉辦《安仔與熊仔：維護國安小公民》教育繪本發布會，一套三冊的繪本以圖畫為主，配合簡單文字及全新故事，向幼兒傳揚維護國家安全的重要概念，培養守法守規意識。保安局局長鄧炳強及教育局副局長施俊輝主持發布儀式。繪本由保安局出版、教育局支持，配合主題兒歌等資源供教師在幼稚園使用；首批繪本將於今年年底前分發至全港超過900間幼稚園及公共圖書館。
